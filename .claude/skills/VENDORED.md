# Vendored skills

Copied from [mattpocock/skills](https://github.com/mattpocock/skills) (MIT, © 2026 Matt Pocock),
commit `d81f3a1` (2026-09-29), without the Codex `agents/` files.

**Local changes** (keep them when updating): `wayfinder` has a section „This repo: autonomous by default“ (decide
what is derivable, park only the human's own decisions as `needs-user` comments, several tickets per session, no
chat interviews); `grilling`, `domain-modeling` and `prototype` fire only on an explicit request (descriptions
narrowed), so autonomous sessions are never turned into interviews.


| Skill | Source | Why here |
|---|---|---|
| `wayfinder` | `skills/engineering/wayfinder` | chart huge, foggy efforts as a decision map on the issue tracker (`/wayfinder`) |
| `grilling` | `skills/productivity/grilling` | used by wayfinder (tickets of type grilling, charting) |
| `domain-modeling` | `skills/engineering/domain-modeling` | used by wayfinder; keeps `GLOSSARY.md` and `docs/adr/` |
| `research` | `skills/engineering/research` | wayfinder's research tickets |
| `prototype` | `skills/engineering/prototype` | wayfinder's prototype tickets |

The repo configuration `setup-matt-pocock-skills` would write is in `docs/agents/` (issue tracker, domain docs)
and the `## Agent skills` block of `AGENTS.md`. To update: copy the folders again from a newer commit and bump the
commit above.

The `openspec-*` skills and `.claude/commands/opsx/` are generated by `openspec init --tools claude`
(`@fission-ai/openspec`, pinned in `package.json`); regenerate them with `npx openspec update` after bumping it.
